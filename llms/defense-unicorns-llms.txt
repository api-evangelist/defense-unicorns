# UDS Documentation

> UDS (Unified Defense Stack) is a secure-by-default Kubernetes platform built on top of Zarf. It packages and operates production applications on air-gapped and internet-connected clusters.

## Products

- **Core**: The platform layer deployed onto a Kubernetes cluster. Bundles Istio (service mesh and ingress), Keycloak (identity and SSO), Authservice (SSO proxy for apps without native OIDC), Prometheus + Grafana + Alertmanager (monitoring), Vector + Loki (logging), Falco (runtime security), and Pepr (policy engine and operator framework). Exposes UDS Package, UDS Exemption, and UDS ClusterConfig CRDs for application and platform integration.
- **CLI**: The command-line tool for creating and deploying UDS Bundles. Wraps Zarf to add multi-package bundles (`uds-bundle.yaml`), a task runner (`uds run`), and cluster monitoring.
